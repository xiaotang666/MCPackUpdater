# MCPackUpdater — MC 整合包更新工具

整合包作者/服主的更新分发工具：生成可手动覆盖的更新包、一键应用更新、备份存档、Mod 对比、检测 Mod 更新。

## 下载
- 最新版请到 [Releases](https://github.com/xiaotang666/MCPackUpdater/releases) 下载 `MCPackUpdater_vX.Y.Z.zip`，解压后双击 `MCPackUpdater.exe` 即可运行（自包含，无需安装运行时）。
- Releases 保留最近 10 个版本。

## 功能
1. 生成更新包：文件夹/导入包输入，客户端/服务端切换，生成的更新包可手动解压覆盖更新
2. 应用更新包：旧 mod 自动进回收站
3. 备份存档
4. Mod 对比
5. 检测 Mod 更新：CurseForge / Modrinth 双平台查询与下载
