# MC 整合包更新工具（MCPackUpdater）

一款面向 Minecraft 整合包作者与服务器管理员的**更新分发工具**：把"旧版本 → 新版本"的差异打成更新包，
玩家**手动解压覆盖即可完成更新**，也可以用本工具一键应用。支持多旧版本合一包、客户端/服务端、
Mod 更新检测等能力。作者：小坣

## 📥 下载

- 前往 [Releases](https://github.com/xiaotang666/MCPackUpdater/releases) 下载最新的 `MCPackUpdater_vX.Y.Z.zip`
- 解压后双击 `MCPackUpdater.exe` 即可运行（自包含，无需安装任何运行时）
- 老版本用户可直接用工具内「检查更新」自动升级

## ✨ 功能

### 生成更新包
- **多基线合一**：可选多个旧版本导入包，生成"其中任意版本 → 新版"的合一更新包（含逐基线兼容性检测）
- **输入灵活**：支持导入包（.zip / .rar / .7z / .tar 等主流格式）或已安装的文件夹，自动识别 CF / mrpack / 平铺等打包形式
- **客户端 / 服务端**一键切换；服务端包自动保护存档、白名单、OP、启动脚本等运营文件
- 更新包**顶层平铺**：玩家手动解压覆盖游戏目录即可更新，无需安装本工具
- 更新包自动命名（含版本区间），并附《更新说明.txt》（含删除清单）

### 应用更新包
- 覆盖新文件 + 旧文件进**回收站**（可恢复），支持 SHA256 校验
- 自动清理历史错位残留，保证升级结果与全新安装一致

### 检测 Mod 更新
- 选择 mods 文件夹自动识别游戏版本与加载器（可手动修改）
- 同时查询 **CurseForge** 与 **Modrinth**，自动选择版本更高的平台，可逐个 Mod 换平台/选版本
- **黑名单 / 白名单**切换、多配置管理（可保存/导入/修改路径）
- 一键下载更新，旧 Mod 进回收站

### 其他
- 备份存档、Mod 对比（含光影/资源包/附属包）
- 6 套配色主题 + 自定义主色、路径记忆、全选/搜索/计数等便捷操作
- 报错精确定位（出错环节 + 具体文件）；模式防呆防止客户端/服务端生成混淆

## 🔒 安全性

- 所有删除操作一律进**回收站**，可随时恢复
- 存档、单人世界、选项、服务器白名单/OP/启动脚本等个人与运营文件**永不覆盖、永不删除**
- 更新包自带完整性校验；生成时逐版本模拟验证，不一致即拒绝生成
