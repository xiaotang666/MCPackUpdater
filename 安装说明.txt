MC 整合包智能更新工具 — 安装说明
================================
功能: 生成更新包 / 应用更新包 / 备份存档 / mod对比

首次使用需安装 .NET 8 运行时:
  https://dotnet.microsoft.com/download/dotnet/8.0

使用方法:
  双击 MCPackUpdater.exe 即可运行
  (若未安装 .NET 8，可改用 启动器.bat 自动检测提示安装)

更新机制:
  GitHub 仓库: https://github.com/xiaotang666/MCPackUpdater
  国内优先走镜像轮询，不可用时回退 GitHub 原始地址
  工具菜单 → 检查工具更新 即可在线升级
