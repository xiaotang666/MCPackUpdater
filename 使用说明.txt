MC 整合包更新工具 v3.3.7（WinUI 3 版）— by 小坣

【运行】
解压 MCPackUpdater_v3.3.7.zip 后，双击 MCPackUpdater.exe 即可运行（自包含，无需安装任何运行时）。

【功能】
1. 生成更新包：选旧/新版本（文件夹或导入包 .zip，自动识别 CF/MCBBS/mrpack/平铺打包形式；旧版本可多选，生成"任意旧版本→新版"多基线合一更新包，含逐基线兼容性检测）→ 对比 → 可勾选保留/替换 mod → 生成平铺 ZIP（手动解压覆盖游戏目录即可更新，无需本工具）→ 支持「生成客户端更新包 / 生成服务端更新包」切换（服务端暂仅支持平铺服务端包/已安装目录，world、白名单、启动脚本等运营文件绝不覆盖/删除）
2. 应用更新包：选更新包 ZIP + 目标目录 → 旧 mod 进回收站 → 覆盖配置/同步加载器
3. 备份存档：备份/恢复存档、路径点、按键绑定
4. Mod 对比：新增/升级/删除/相同 + 导出新增与升级 mod（支持导入包作为输入）
5. 检测Mod更新：选 mods 文件夹 → 自动识别游戏版本与加载器（可手改）→ 同时查询 CurseForge 与 Modrinth → 默认选版本号更高平台（可逐个换平台）→ 逐个选择下载版本（默认最新）→ 一键下载到 mods 文件夹，旧版本进回收站

【界面】
- PCL 蓝渐变风格，右上角"配色"可切换 6 种主题或自定义主色
- 等比布局，不同分辨率/缩放自动适配

【更新】
标题栏"检查更新"可检测新版本并自动下载更新。

【旧版(v2.x)用户注意】
旧版内置"检查更新"无法自动升级到 v3.x（v3 为目录版，无单文件 exe）。若点击检查更新后出现"不支持的 16 位应用程序"报错：
1. 该文件其实已是完整新版压缩包：把 MCPackUpdater.exe 重命名为 MCPackUpdater_v3.3.7.zip，解压即得新版；
2. 或删除损坏的 MCPackUpdater.exe，到 GitHub Releases 下载最新 zip 解压使用。
